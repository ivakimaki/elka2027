# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: «Новогодняя Ёлка 2027»
## Telegram Mini App + Supabase Backend

> **Актуализация:** исправлена синхронизация `isNew` у пользователя, устранена проблема с отображением ёлки при старте, оптимизировано логирование в отладочной панели `debug.js`.

## 1. АРХИТЕКТУРА И СОСТОЯНИЕ
- Клиент корректно синхронизирует состояние с Supabase при старте через `tg-auth`.
- Полив (`do-water`) и визиты (`do-visit`) полностью синхронизированы с базой данных.
- Отладка доступна через кнопку 🔍 в правом нижнем углу и скрытую панель по 3 тапам на гирлянду.
