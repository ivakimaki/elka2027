# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: «Новогодняя Ёлка 2027»
## Telegram Mini App + Supabase Backend

> **Актуализация:** исправлена интеграция полива (`do-water`), добавлено логирование и расширена отладка через `debug.js`.

## 1. АРХИТЕКТУРА И СОСТОЯНИЕ
- Клиент синхронизируется с Supabase при старте (`tg-auth`).
- Полив (`do-water`) корректно отправляет запросы на эндпоинт и обновляет базу данных пользователя.
- Отладка доступна через кнопку 🔍 в правом нижнем углу и скрытую панель по 3 тапам на гирлянду.
